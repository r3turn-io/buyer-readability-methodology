# Public Boundary

This repository may contain only content that is already public on the canonical methodology page, or that is required to administer this public record (rights notice, citation metadata, changelog, and this boundary).

Canonical web publication:

https://www.r3turn.io/en/methodology

Default:

If uncertain -> REVIEW_REQUIRED.

## PUBLIC_SAFE

May be published in this repository without additional review when it already appears on the canonical methodology page, or when it is administrative record-keeping for that already-public methodology.

Examples:

- terminology already published on the canonical methodology page
- current public 5+1 domain definitions
- public interpretation-layer definitions
- DRG public definition
- DHG public definition
- public FAQ
- public Suggested Citation
- public methodology version history

## REVIEW_REQUIRED

Must not be added to this repository unless separately reviewed and approved for public methodology publication.

Examples:

- new terminology
- expanded scoring descriptions
- anonymized customer examples
- new diagrams not already public
- public schemas
- checkpoint detail
- scoring-like outputs
- internal-to-public methodology mappings

## NEVER_PUBLIC

Must not enter this repository.

Examples:

- proprietary scoring weights
- deterministic engine implementation
- private audit logic
- private collectors
- customer evidence
- customer data
- private prompts
- internal adjudication
- private operational schemas
- private repository content
- unpublished methodology
