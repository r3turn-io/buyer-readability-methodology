# R3TURN Buyer Readability Methodology

Public record of the R3TURN Buyer Readability Methodology: a 5+1 audit framework for how exporters are discovered, interpreted, and verified before direct buyer contact.

Current public version:

v4.1

Canonical web publication:

https://www.r3turn.io/en/methodology

## Repository role

A versioned public reference and citation record for the R3TURN Buyer Readability Methodology.

The web methodology page remains the canonical current publication. This repository is the versioned public record of that already-public methodology.

## Boundary

This repository documents the public methodology.
It does not contain R3TURN's proprietary scoring implementation, internal audit logic, private evidence systems, or customer data.
